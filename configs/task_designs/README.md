# 餐桌任务设计库(100 个)

为 `configs/environments/` 现有 19 个餐桌任务扩充的**新任务设计集**。每个任务是一张
"图纸"的设计蓝本:包含任务名、类别、感官模态、难度、核心物品清单(形状/尺寸/材质/
重量,与设计工具建模字段对应)、背景摆放与给采集员的分步操作指令(`notes`)。

## 文件

| 文件 | 说明 |
| --- | --- |
| `餐桌任务设计_100.yaml` | 全部 100 个任务的完整设计(meta 统计 + 逐任务字段) |
| `餐桌任务设计_100_index.csv` | 索引表,便于快速浏览/筛选(Excel 可直接打开) |
| `generator/` | 生成器:96 个任务族定义 + 构建脚本,可重新生成或扩量 |

## 一览(100 个)

- **类别分布(13 类,每类 7-8 个)**:饮品制作 7、茶席咖啡 8、餐桌布置 7、食物处理 7、
  **触觉辨识 8**、插入封装 8、工具使用 8、清洁整理 8、量取分装 7、传递交换 8、
  收纳归位 8、综合流程 8、补充场景 8
- **模态分布**:**视觉+触觉 91 个,视觉主导 9 个**(满足"一部分任务必须具备触觉+视觉",
  且触觉占比过半,保证触觉数据密度)
- **难度分布**:简单 38 / 中等 50 / 困难 12

## 触觉任务的设计标准

一个任务标注为"视觉+触觉"的条件是:**任务成功必须依赖触觉反馈**,仅靠看无法完成。
每个触觉任务的 `tactile` 字段写明触觉要素,按七类组织( YAML meta 中有逐类计数):

| 触觉要素类 | 典型任务 |
| --- | --- |
| 力控/握持 | 薯片装碗不碎(捏力上限)、湿滑冰块夹取、玻璃罐防滑 |
| 重量/掂重 | 掂重分拣满空杯、掂重排序、倒水前后壶身轻重 |
| 纹理/质感 | 纹理配对(砂/绒/丝/毛圈)、筷子盲配对(刻纹vs光面)、表皮辨水果 |
| 软硬/干湿 | 软硬分拣、干湿毛巾分类、剥香蕉(果肉软硬) |
| 温度感知 | 辨温选壶倒水、温水杯辨识(安全:温水不烫手)、冰袋冷敷 |
| 盲辨/触觉定位 | 布袋摸物分类、遮挡插孔定位、盲摆三点一线、盲剥橘/蛋 |
| 旋拧/插入到位 | 保温杯旋盖、保鲜盒四角咔哒、吸管刺破封膜、瓶盖扭矩 |

触觉指令写入 `notes` 的方式与现有图纸一致:在步骤中给出**手感判据**
(如"拧到手感突然变松即为完全打开""搅到阻力变顺滑为止"),并常配
**触觉→视觉交叉验证**(如"摸完睁眼核对颜色"),保证数据可自检。

## 与现有 19 个任务的关系

- 命名沿用 `餐桌_任务名` 惯例,**与现有任务无一重名**;现有任务为核心操作
  (倒水/倒茶/做三明治等),本设计集在深度(触觉辨识、力控、盲操作)和
  广度(茶席、工具、量取、综合流程)上补全。
- 网格引用沿用现有 notes 的写法:面前 `O/K/P/L格`、中心 `N/G格`、
  右下角 `F/C格`、左下角 `R/V格`。
- 背景摆放沿用惯例(花/水杯架/炒菜/抽纸/垃圾桶等)。

## 接入流程(变成可采集的图纸)

1. 在图纸设计工具中按任务的 `objects` 建模物品(字段对应:shape=`cyl`(d,h)/
   `box`(h,l,w)、material、weight,g 单位;尺寸 cm)。
2. 把 `notes` 整段粘贴到该任务的 `scene.notes`。
3. 生成 placements 与图纸 png,整体放入
   `configs/environments/餐桌_<任务名>/`,采集程序会自动进抽取池
   (README 采集手册:"新图纸放到 configs/environments/ 即可")。
4. 涉及新物品的先在物品库建档(照片/缩略图/obj_id)。

## 重新生成与扩量

```bash
cd configs/task_designs/generator
python build.py --total 100   # 当前交付(候选池共 489 个,可扩到 489)
python build.py --total 300   # 需要更多任务时
```

筛选规则:13 个类别轮转均衡抽取,每个任务族先出"基础版"再出变体,保证类别
覆盖均匀、族内变体不扎堆。改 `-–total` 即可,产物文件名自动带数量。

## 安全约定

- 温度类任务一律用**温水/温敷**(≤45℃,不烫手),不涉及明火与高温。
- 切割用**塑料刀/削皮器/剪刀**等低风险工具,无刀具快切动作。
- 食物类可用仿真道具替代(设计工具建模一致即可)。
- 蜡烛、牙签等尖端物品仅做**插入摆放**,不点燃。
